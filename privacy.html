개인정보처리방침

대상: Gorani Uploader (경제고라니 채널 운영 도구) · 시행일 2026-11-16

1. 무엇을 하는 도구인가요

Gorani Uploader는 경제고라니 운영자 한 사람이 쓰는 개인용 도구입니다. 운영자가 만든 영상을 운영자 본인의 유튜브 채널에 업로드하고, 그 영상에 첫 댓글을 다는 일만 합니다. 다른 사람의 계정에 로그인하거나 다른 사람의 데이터를 다루지 않습니다.

2. 어떤 정보를 쓰나요

유튜브 Data API를 통해 운영자 본인 채널의 기본 정보(채널 ID·이름), 업로드한 영상의 상태, 그리고 운영자가 다는 댓글만 사용합니다. 시청자 개인정보는 수집하지 않습니다.

3. 어디에 저장하나요

구글 로그인으로 받은 인증 토큰은 운영자의 개인 컴퓨터에만 저장되며, 외부 서버로 보내거나 제3자와 공유하지 않습니다. 광고·분석·판매 목적으로 쓰지 않습니다.

4. 권한 철회

운영자는 언제든지 구글 계정 권한 페이지에서 이 도구의 접근을 철회할 수 있고, 저장된 토큰은 컴퓨터에서 삭제하면 사라집니다.

5. 구글 API 정책 준수

Gorani Uploader가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(Limited Use 요건 포함)을 따릅니다. 유튜브 API 사용은 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.
